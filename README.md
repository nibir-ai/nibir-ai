## 🚀 Featured Projects

### 🔊 [XBMind](https://github.com/nibir-ai/XBMind)
> Turn any Bluetooth speaker into an **offline AI smart speaker** — pure Python, zero cloud, zero hardware mods.

Wake word detection → **Whisper STT** → local LLM via **Ollama** → **Piper TTS** → audio out. Runs entirely on Linux. Your data never leaves your machine.

`Python` `Whisper` `Ollama` `Piper TTS` `Linux` `Edge AI`

---

### 👁️ [datasetvision](https://github.com/nibir-ai/datasetvision)
> **Offline CV dataset auditing CLI** — catch problems *before* training starts.

Detects anomalies, near-duplicates, data drift, corruption, and class imbalance across image datasets. Because bad data is the #1 reason models fail.

`Python` `OpenCV` `Typer` `Data Quality` `Computer Vision`

---

### 🧮 [micro-tensor](https://github.com/nibir-ai/micro-tensor)
> A **lightweight autograd engine built from scratch.**

Because the best way to understand deep learning isn't to import a framework — it's to build one. Forward passes, backward passes, gradient tape — all of it, from first principles.

`Python` `Autograd` `Backpropagation` `From Scratch`
